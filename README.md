# ZATO_Designer
Image redactor that can do backgrounds photo from game Z.A.T.O.

# Installing (Windows)
1. Install python 3.13.7+ with [link](https://www.python.org/downloads/);
2. Open Command Line;
3. Install pillow and numpy with command:
````bash
pip install pillow numpy
````
4. Download project (or just ZATO_Editor.py file);
5. Run program with:
````bash
python ZATO_Editor.py
````
6. Enjoy!!!

# Uninstalling (Windows)
1. Delete folder with program (or just "ZATO_Designer.py" file)
## Additionally
2. Open Command Line
3. Uninstall pillow and numpy:
````bash
pip uninstall pillow numpy
````
4. Uninstall python (you can use Control Panel with all your apps to delete python like any other)
